Messenger Pro BD - PWA Ready

This package is prepared to be installed as an Android-style PWA without Android Studio.

1. Upload the contents of messenger_v34 to any HTTPS static host.
2. Open the HTTPS site in Chrome.
3. Use the browser Install/Add to Home Screen option.
4. For an APK package, open the public HTTPS URL in PWABuilder and choose Android.

Important: Firebase web push requires HTTPS and the existing Firebase messaging configuration.
Do not expose or share private AI/TTS API keys; client-side keys can be viewed by users.
